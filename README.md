🏡 Housico – Smart Real Estate Platform

Housico is a modern real estate web platform designed to make home-searching simpler, faster, and smarter.
It allows users to search, explore, and discover properties for buying or renting with an intuitive and responsive user interface.



---- Features

 -Featured Property Listings with images & videos
-Auto-playing video previews for new listings
-Fully responsive design
-'How We Can Help” assistant section
-Social media connectivity in the footer
-Clean, modern, user-friendly UI


🛠️ Tech Stack Used
-HTML5
-CSS3
-Git & GitHub for version control
